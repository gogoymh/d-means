# 한국어 윤문 가이드

에이전트가 쓰는 한국어 글에서 기계가 번역한 듯한 표현과 종결어미 불일치를 없애는 기준입니다.

## 적용 범위와 원칙

- **적용 대상**: `#general` 메시지, 이슈 제목과 본문, 댓글, 완료 기준, 작업 요약처럼 사용자가 읽는 한국어 글에 적용합니다.
- **영어 문서 유지**: 저장소의 `README.md`, 코드 주석, 커밋 메시지는 `CLAUDE.local.md` 규칙대로 영어로 씁니다.
- **원래 뜻 유지**: 파일 이름, 명령어, 티켓 번호, 실제 동작과 사실은 바꾸지 않고 표현만 자연스럽게 다듬습니다.
- **종결어미 통일**: 한 글 안에서 말투를 하나로 맞춥니다. 채널 메시지, 댓글, 작업 요약은 합쇼체(`~합니다`, `~했습니다`)로 쓰고, 완료 기준이나 항목 목록은 평서체(`~한다`)로 통일합니다.

## DM-22와 DM-25에서 나온 패턴과 고친 예

### 1. 무생물 주어 '~이 ~를 보여 준다'

영어의 `X shows Y`를 그대로 옮겨 화면이나 파일 같은 무생물을 행위 주체로 세우지 않습니다. 화면에 무엇이 나타나는지 자연스러운 한국어 술어로 바꿉니다.

- 원문 (DM-25): `README 첫 화면이 구슬로 된 D 배너를 보여 준다.`
- 고친 예: `README 첫 화면에 구슬로 된 D 배너가 나옵니다.`
- 원문 (DM-26): `구슬 배너 히어로는 워드마크 'D-means'만 보여 준다.`
- 고친 예: `구슬 배너 히어로에는 워드마크 'D-means'만 나옵니다.`

### 2. 영어 직역투 '범위가 잘린 티켓'

`cut-scope`나 `trimmed scope`를 직역하면 한국어에서 쓰지 않는 조합이 됩니다. 문맥에 맞게 범위가 줄었는지 제외됐는지 드러나게 씁니다.

- 원문 (DM-22): `결제·계정·결정이 필요하거나 범위가 잘린 티켓은 건너뛰고`
- 고친 예: `결제, 계정, 결정이 필요하거나 범위가 줄어든 티켓은 건너뛰고`
- 참고: 작업 범위에서 아예 제외된 티켓이라면 `범위에서 빠진 티켓`으로 씁니다.

### 3. 영어 직역투 '가장 분명한 작은 일'

`the clearest small task`를 단어 그대로 옮기면 무엇이 분명하다는 뜻인지 모호합니다. 지금 바로 끝낼 수 있는 작업이라는 뜻을 직접 씁니다.

- 원문 (DM-22): `코드만으로 끝낼 수 있는 배너 미리보기가 지금 가장 분명한 작은 일이다.`
- 고친 예: `코드만으로 끝낼 수 있는 배너 미리보기가 지금 바로 처리할 수 있는 작업입니다.`

### 4. 어색한 외래어 명사구 '배너 렌더'

`banner render`를 그대로 들여오면 렌더링 코드인지 결과 이미지인지 흐려집니다. 실제 대상을 가리키는 말로 바꿉니다.

- 원문 (DM-25): `방금 머지된 배너 렌더가 README 첫 화면에 아직 안 쓰여, 라이트·다크 히어로로 바로 갈아끼우면 된다.`
- 고친 예: `방금 병합된 배너 이미지가 README 첫 화면에 아직 들어가지 않아, 라이트와 다크 히어로로 바로 바꾸면 됩니다.`

### 5. 한 메시지 안의 존댓말과 반말 혼용

앞 문장을 합쇼체(`~했습니다`)로 시작한 뒤 다음 문장에서 해라체(`~이다`, `~된다`, `~보여 준다`, `~빠졌다`)로 꺾으면 문장을 어색하게 이어 붙인 글처럼 읽힙니다. 한 메시지 안의 종결어미를 하나로 맞추고, 설명하는 대상이 바뀌면 문장을 나눕니다.

- 원문 1 (DM-22):
  `미션 DM-22(으)로 맡았습니다. 결제·계정·결정이 필요하거나 범위가 잘린 티켓은 건너뛰고, 코드만으로 끝낼 수 있는 배너 미리보기가 지금 가장 분명한 작은 일이다.`
- 고친 예 1:
  `미션 DM-22를 맡았습니다. 결제, 계정, 결정이 필요하거나 범위가 줄어든 티켓은 건너뛰었습니다. 코드만으로 끝낼 수 있는 배너 미리보기가 지금 바로 처리할 수 있는 작업입니다.`

- 원문 2 (DM-25):
  `미션 DM-25을(를) 마쳐 병합했습니다: README 첫 화면이 구슬로 된 D 배너를 보여 준다. 밝은 화면은 라이트 PNG, 어두운 화면은 다크 PNG이고, 금속 D 사진 d-means-hero.jpg는 빠졌다.`
- 고친 예 2:
  `미션 DM-25를 마쳐 병합했습니다. README 첫 화면에 구슬로 된 D 배너가 나옵니다. 밝은 화면에는 라이트 PNG, 어두운 화면에는 다크 PNG가 나오며 금속 D 사진 d-means-hero.jpg는 뺐습니다.`
